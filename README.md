# LitematicaTool

A simple tool designed to work with Litematica for enhanced schematic management.

## Features

- **The Stick**: A special tool designed specifically for use with Litematica
- **Stack Size**: Limited to 1
- **Multi-Language Support**: English, Chinese, German, Spanish, and French


## How to Use

1. **Open Litematica Menu**: Press `M` in-game
2. **Access Configuration**: Click the "Configuration Menu" button on the "Generic" tab
3. **Find Tool Setting**: Search for "tool" in the configuration
4. **Replace Tool**: Change `minecraft:stick` to `litematicatool:the_stick`
5. **Save and Exit**: Your chosen tool for Litematica will now be the Litematica Tool
